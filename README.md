# Sistema de Estoque

Sistema de gerenciamento de estoque desenvolvido em Python para praticar lógica de programação, funções, listas, dicionários e manipulação de arquivos.

## Funcionalidades

- Adicionar produtos
- Listar produtos
- Buscar produtos
- Alterar quantidade
- Remover produtos
- Ver resumo do estoque
- Salvar os dados automaticamente em JSON

## Tecnologias

- Python
- JSON

## Como executar

```bash
python estoque.py
```

O arquivo `estoque.json` é criado automaticamente quando um produto é cadastrado.

## Objetivo

Projeto criado para praticar Python e desenvolver um sistema simples de gerenciamento de estoque.
